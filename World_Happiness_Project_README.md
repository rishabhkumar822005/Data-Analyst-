# World Happiness Report 2023 -- Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the World
Happiness Report 2023 dataset to understand how happiness scores vary
across countries and how different social and economic factors relate to
happiness.

## Dataset

-   Dataset: World Happiness Report 2023
-   CSV file: `WHR2023.csv`
-   Records: 137 countries
-   Features: 19 columns

## Analysis Performed

-   Loaded and inspected the dataset using Pandas.
-   Checked data types, missing values, and duplicate records.
-   Explored descriptive statistics for happiness scores.
-   Identified the 10 happiest and 10 least-happy countries.
-   Examined correlations between happiness and selected factors.
-   Created visualizations to communicate the findings.

## Tools and Libraries

-   Python
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Google Colab

## Key Findings

-   Finland had the highest happiness score in the dataset.
-   Afghanistan had the lowest happiness score.
-   Social support and logged GDP per capita showed strong positive
    correlations with the happiness score.
-   The analysis describes associations in the dataset; correlation does
    not establish causation.

## How to Run

1.  Open `World_Happiness_EDA_Project.ipynb` in Google Colab.
2.  Upload `WHR2023.csv` when prompted, if it is not already available.
3.  Run the notebook cells from top to bottom.

## Dataset Source

World Happiness Report 2023 dataset supplied for this project.

## Conclusion

The analysis explores country-level happiness scores and their
relationship with social support, GDP per capita, healthy life
expectancy, freedom, generosity, and perceptions of corruption.
