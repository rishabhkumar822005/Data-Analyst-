# Heart Disease Prediction Using Machine Learning

Pluto Academy Project 02.

## Notebook
`Heart_Disease_Prediction_Project.ipynb`

## Dataset
Download `heart_2020_cleaned.csv` from:
https://zenodo.org/records/15364962

Original survey documentation:
https://www.cdc.gov/brfss/annual_data/annual_2020.html

## Models
1. Logistic Regression
2. Random Forest
3. K-Nearest Neighbors (KNN)

## Required outputs
- Preprocessing and feature engineering
- 80/20 stratified train/test split
- Comparison table with Accuracy, Precision, Recall, F1-score, and ROC-AUC
- Best-model confusion matrix
- Random Forest feature importance
- Five-line conclusion generated from actual results

## Run
Open the notebook in Google Colab, run cells from top to bottom, and upload `heart_2020_cleaned.csv` when prompted. The notebook uses stratified samples for practical training on Colab/mobile.

## Limitation
This dataset contains self-reported U.S. survey data from 2020. It is not current hospital data and is not suitable for clinical diagnosis or treatment decisions. Educational use only.
